Move from another server

You can move an existing Vaultwarden server to a new deployment. The examples use the MinIO client (mc), with an alias called tigris for your bucket. Any S3 tool works.

  1. Deploy the new server with the install guide.

  2. Stop the old server, so nothing changes while you copy. If you can’t stop it and still reach its files, run this SQL command on its database. It writes all pending changes into the database file:

  3. Upload the database and import it. With IMPORT_DATABASE set, the server loads this file on start.

  4. Check the logs with fly logs. Look for the import and for Litestream finishing its upload. Then deploy again without the variable:

    Caution

    Don’t leave IMPORT_DATABASE set. Every restart would replace your live database with the old file.

  5. Copy the RSA key, so users stay logged in:

  6. Copy attachments and Sends to data/ in the bucket. The icon cache is optional.

  7. Copy your settings. Look at the old config.json and environment. Set the matching VAULTWARDEN_* variables. See Settings.

To check the result, log in and download an attachment.
