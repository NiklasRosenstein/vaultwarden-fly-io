Install

You need

Section titled “You need”
  • A Fly.io account
  • The fly command-line tool, logged in
  • The age command-line tool, to create an encryption key

Steps

Section titled “Steps”

  1. Create the app.

  2. Create a bucket. This also saves the bucket’s credentials as secrets on the app.

  3. Create two keys. Vaultwarden signs logins with the RSA key. The age key encrypts the database copy.

    Danger

    Without AGE_SECRET_KEY your database can’t be restored. Keep a copy of both keys somewhere safe, outside Fly.io.

  4. Create an admin password. This prints a hashed version of the password you type.

  5. Write your fly.toml. Copy fly.example.toml. Set the app name, your domain, the admin hash from step 4, and the latest image version.

  6. Deploy. --ha=false creates a single machine. This setup must never run more than one.

Your vault is now at https://<app_name>.fly.dev. To use your own domain, add a certificate.

Next steps

Section titled “Next steps”
  • Once your accounts exist, stop new sign-ups: VAULTWARDEN_SIGNUPS_ALLOWED = "false".
  • Set up email for invitations and verification.
  • Turn on backups.
