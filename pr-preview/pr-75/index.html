Vaultwarden on Fly.io

Your own Bitwarden-compatible password manager on a small Fly.io machine, for about 2 USD a month. All data lives in an S3 bucket, so the machine itself can be replaced at any time.
Get startedView on GitHub

Cheap

The smallest machine costs about 2 USD a month. Fly.io stops it when nobody uses it. See Costs.

No disk needed

Your database and files are stored in an S3 bucket. A new machine picks up where the old one stopped.

Backups built in

Turn on backups to keep an extra encrypted copy of your vault in a second bucket.
