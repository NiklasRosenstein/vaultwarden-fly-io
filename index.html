Vaultwarden on Fly.io

Your own Bitwarden-compatible password manager on a tiny Fly Machine, for about 2 USD a month. SQLite is replicated to S3 by Litestream, so the VM itself is disposable.

Why this setup?

Section titled “Why this setup?”

Cheap to run

The smallest shared-cpu-1x VM costs about 2 USD a month, and Fly.io stops it when nobody uses it. On a personal account, Fly.io has so far waived invoices under 5 USD. Storage and requests usually fit Tigris’s free tier.

No volumes

The SQLite database is restored from S3 on boot and continuously replicated back with Litestream, encrypted with age.

Attachments in S3

Attachments, Sends and the icon cache live in the same bucket, mounted with GeeseFS.

Configuration as code

Vaultwarden’s config.json is built from environment variables on every start. Your fly.toml holds the whole configuration.

Self-healing storage

A monitor watches the S3 mount and restarts the machine when the mount breaks. It holds off while the S3 provider itself is down.

Scheduled backups

An optional worker writes age-encrypted, self-contained archives of your vault to a separate bucket on a schedule.
